## ⚠️ Important Notes

- The overseas spend is exactly at 20.00%. The spreadsheet rule says "less than 20%". If it flags red, reduce one overseas cost by $1 (e.g., Character Artist from $22,000 to $21,999).
- Do NOT drag and drop cells — type values directly.
- Wait for the progress bar after each entry before moving to the next cell.
- Orange cells can be ignored at application stage.
- If you run out of rows on any tab, email funding@nz-code.nz to request more.
